# 首次运行与迁移

本 skill 是制作流程和模板，不包含视频渲染引擎、新闻图片、音乐、系统字体或账号。支持本地文件与浏览器的 Codex/兼容代理环境；仅能聊天、不能运行命令或保存文件的环境不能完成本地出片。

## 前置工具

| 工具 | 用途 | 缺失时 |
| --- | --- | --- |
| Python 3.9+ | 可选的热点采集与目录/依赖检查；脚本仅用标准库 | 可由代理自身联网工具代替采集；脚本需先安装 Python |
| Node.js、npm/npx | 调用 HyperFrames CLI | 按 HyperFrames 当前官方要求安装支持的 Node.js 版本 |
| HyperFrames CLI 与对应技能/插件 | 初始化、校验、预览、渲染 | 安装官方 HyperFrames 插件或 CLI，并遵循该安装形态的说明；不要混用插件与全局技能更新规则 |
| Chrome/Chromium 或 HyperFrames 支持的浏览器 | 页面渲染与实际播放检查 | 使用 HyperFrames 的 browser/doctor 指引检查，不能仅靠 HTML 文件声称已出片 |
| FFmpeg 与 ffprobe | 编解码、音轨处理与最终文件核验 | 安装并加入 PATH，或按 HyperFrames doctor 提示配置 |
| 可用的中文字体 | 正确显示中文与字重 | 选择本机字体或有明确许可的开放字体，复制到当前工程并声明 @font-face |

Easel、Hypit、ChatCut、图像生成服务和音乐服务都不是此流程必需依赖。默认网络原图、截图和信息图，静音；只有请求相关能力时再配置对应服务。付费服务不自动开通。不要把制作者电脑的工具路径、密钥或字体复制给接收者。

先运行：

```bash
python3 <技能目录>/scripts/preflight.py --workspace <工作区绝对路径>
```

这是本地只读检查，不下载工具、不创建目录、不验证浏览器或中文字体实际可用。它只确认可执行文件和目录位置；再按实际安装运行 HyperFrames 的 doctor，并核验字体。使用 `npx` 首次运行可能下载 CLI 及依赖、访问网络；已有安装时按对应工具说明执行。CLI 版本以本机检查和该版本官方说明为准，不把历史成功版本当作永久要求。

官方工具入口：https://hyperframes.heygen.com/llms.txt 。需要具体安装命令时先查当前官方说明，不猜版本。需要读取热点时再访问 AIHOT，已指定新闻则无需访问热点接口。

## 输出与可移植性

工作区绝不能放在技能安装目录内。默认使用当前项目下 `outputs/wechat-news-card/`，也可明确指定其他文件夹。每条工程固定自己的素材副本；媒体引用使用工程相对路径，不依赖全局素材或临时剪贴板位置。

系统字体的可用性和再分发权不同。技能分享包不带作者系统字体；接收者在自己的工程选用字体。历史字体不同可能导致换行变化，必须重新检查文字宽高和封面裁切。

## 可选采集

```bash
python3 <技能目录>/scripts/fetch_hot.py --out <工作区>/inbox/热点候选/source
```

采集脚本拒绝向技能目录写入。没有密钥不代表素材可再分发，新闻图片和 BGM 按各自来源记录许可；技能 ZIP 不打包历史下载媒体。
