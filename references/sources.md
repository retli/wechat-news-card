# 选题与来源

AIHOT官方入口 https://aihot.news/agent ，Agent说明 https://aihot.news/api/v1/agent ，当前热点 https://aihot.news/api/v1/agent/hot 。无需API Key。
按返回热点顺序挑约5个相关候选，不能把信源数量等同于热度。事件详情使用返回的来龙去脉地址，不猜链接。JSON接口定义 https://aihot.news/openapi-v1.json 用于程序化同步；不要把选题资料当成已核验新闻。

保存获取时间、站内链接和原文出处。标题和摘要只是资料；原文不足时不补造信息。模型定价注明单位、时间/折扣阶段；评测注明基准与比较条件；厂商自述标明归属。
公开items接口未提供配图字段。原型本机读取AIHOT阅读页曾遇403；不能承诺每篇自动获取全文和图片，也不绕过访问限制。可从可访问的原始链接另行准备。

低频按需请求、使用超时；遵循缓存与Retry-After。连续失败明确报告，不无限重试。官方规则 https://aihot.news/terms ：个人非商业/内部用途与商业外部用途范围不同；商业使用或批量再分发前确认对应授权。不把“接口无需Key”解释为素材许可。
