# 视频号资讯卡片 skill

制作固定三段布局的8～13秒资讯卡片短视频，默认静音，输出视频、独立封面、纯文本发布简介与可编辑 HyperFrames 工程。支持 AIHOT 选题及自定义新闻主题。标题默认先给3～4条有不同钩子的候选，集中一次确认。

## 安装

解压得到 `wechat-news-card` 文件夹，放到 Codex 技能目录：默认 `~/.codex/skills/`；若已设置 CODEX_HOME，则使用其 `skills/` 子目录。最终应能找到 `wechat-news-card/SKILL.md`。重新打开会话，让代理发现技能。

若已安装同名版本，先保留旧目录备份再替换。不要把安装目录当作视频项目目录。

本包仅提供 skill，不含 HyperFrames 引擎及其插件。首次出片前请让代理阅读 `references/setup.md`：准备 Node.js/npm、HyperFrames、支持的浏览器、FFmpeg/ffprobe 和中文字体。Python 3.9+ 用于随包的检查和采集脚本。Easel、Hypit 及付费生图/音乐工具不是必需项。

## 使用

在自己的项目目录发起：

“使用 wechat-news-card，选题为［新闻链接或主题］。先给标题和素材方案，我确认后制作。”

或：

“使用 wechat-news-card 获取当前热点，给我候选列表。”

默认输出到当前项目 `outputs/wechat-news-card/`。也可在请求中指定保存位置。所有生成内容与技能安装目录隔离；最终回复包含实际保存路径。

模板中的文案与图形均为通用排版示例，不是新闻事实，也不是可直接导出的动画工程。正式出片使用已核实的新闻和本地素材，通过 HyperFrames 时间轴制作与校验。模板保留固定布局，正式工程加载实际选用的中文字体。

不包含历史成片、人物图片、BGM、系统字体、个人路径、账号或 API Key。不能保证标题爆款或平台审核通过；上传发布需要单独指示。
